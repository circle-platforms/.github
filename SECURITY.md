# Security policy

Every circle-platforms repository has GitHub private vulnerability reporting enabled: open the repository's **Security** tab and choose **Report a vulnerability**. Do not disclose details in public issues.

Include the affected repository and version or commit, a minimal reproduction, the impact and the relevant files. Do not upload credentials, tokens, internal addresses, raw business data, device output or full agent sessions.

The projects are under development and are not supported production releases; there is no production response-time commitment at this stage. What each project does and does not protect is written in its own `SECURITY.md`: [circle](https://github.com/circle-platforms/circle/blob/main/SECURITY.md) · [circle-hub](https://github.com/circle-platforms/circle-hub/blob/main/SECURITY.md) · [circle-packs](https://github.com/circle-platforms/circle-packs/blob/main/SECURITY.md).
