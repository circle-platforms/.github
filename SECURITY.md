# Security policy

The two public product repositories, circle and circle-hub, have GitHub private vulnerability reporting enabled: open the affected repository's **Security** tab and choose **Report a vulnerability**. Do not disclose details in public issues. The `.github` repository holds organization profile and community documents; it does not provide a separate private vulnerability reporting inbox.

Include the affected repository and version or commit, a minimal reproduction, the impact and the relevant files. Do not upload credentials, tokens, internal addresses, raw business data, device output or full agent sessions.

The projects are under development and are not supported production releases; there is no production response-time commitment at this stage. What each project does and does not protect is written in its own `SECURITY.md`: [circle](https://github.com/circle-platforms/circle/blob/main/SECURITY.md) · [circle-hub](https://github.com/circle-platforms/circle-hub/blob/main/SECURITY.md).
